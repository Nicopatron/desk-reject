# Rules pending

Where drift goes **before** it becomes a rule (R11).

Something the editor should probably catch, but for which no quotable constraint exists yet, lands here — not in `rules.md`. A rule invented on the spot and enforced against a real author's abstract is the editor doing to them what it exists to stop them doing to a reader: asserting more than it can carry.

A row leaves this file in one direction only: someone finds the source, cites it, and the rule enters `rules.md` with its provenance. Nothing graduates because it felt right often enough.

## Open

| What | Why it isn't a rule | What would promote it |
|---|---|---|
| **Limitations line in an abstract** | The operator's corpus requires limitations of the *manuscript* and is silent on abstracts. No venue's rules are in hand. | Any of the five congresses' real abstract instructions requiring one. |
| **Ethics / funding / consent statements in abstracts** | Same gap — corpus lists them under *Original Article*. | Same. |
| **Word count / structured-vs-unstructured per venue** | Not in the corpus for any of the five. Also **deliberately** out of scope: the submission portal enforces word count, so it's the most visible failure there is, and R7 spends the budget on invisible ones. | Would need a reason to exist beyond availability. Probably never graduates. |
| **TNM staging claims** | The corpus points at the 8th-edition tables without containing them. "Stage III" is not checkable here. | Bringing in the UICC/AJCC tables and citing them item by item. Nobody on this build has opened them. |
| **STROCSS 2024 item numbers** | The *version* is verified (PMID 38445501). The checklist's internal numbering is not — the PDF hasn't been opened. | Opening it. Until then the editor cites the guideline, never an item number. |
| **Seven other guideline versions** (CONSORT, STROBE, CARE, PRISMA, STARD, SQUIRE, ARRIVE) | Dates come from the corpus, unchecked against official sites. The corpus has already been demonstrably stale once — STROCSS 2021, superseded by 2024, caught 2026-07-17. | Checking each against its official site. |
| **`rewrite-gate.py` is blind to an unquoted replacement** | Three of its four classes require a quoted span in the clause; the fourth is a fixed phrase list. A declarative that supplies the author's phrasing without quoting it — *"what the data support is that X was associated with Y"* — matches none of them and clears the gate. Observed 2026-07-22 in a real run, in [`examples.md`](../examples.md) §4 — and **not** reproduced when the same input was rerun against the same build, so the trigger is intermittent and no failing test can be written for it yet. The quote-anchoring is deliberate, not an oversight: R3 makes the editor quote the author in every finding, so a gate that fires on quoted text fires on the editor working. | A test that separates *the editor restating what the evidence supports* (legal, and most of what a critique is) from *the editor composing the author's clause* — without firing on R3. Patching the detector against this one observed miss would teach it the example instead of the class. Until then the gate catches the framed rewrite and misses the unframed one, and this file is where that is written down. |
| **Prospective comparative, unadjusted — which ceiling?** | It matches no row of R5's table: row 2 is retrospective-only, row 3 requires adjustment. The editor refuses rather than rounding, and R5 publishes the refusal, so the gap is visible instead of silently patched. Reviewed 2026-07-22 and deliberately **not** closed: three independent reviewers refused the proposed widening of row 2. The objection that decided it is a detector problem, not an epidemiological one — *"retrospective analysis of a prospectively maintained database"* is standard phrasing, and there the word **prospective** describes the data source, not the design. | A domain review by an epidemiologist or a surgeon, **and** a way to tell a prospective design from a prospectively maintained database. Widening the row before that hands a ceiling to a phrase rather than to a study. |
| **Two arms with their own n, read as a comparison group** | R2 item (3) counts two declared `n` as a stated comparison — the rule added 2026-07-22 so that two named arms stop reading as single-arm. A **development and a validation cohort** also carry two n and are not two arms of a comparison; this rule would read them as one. No abstract in hand shows the case, so it is a known edge, not a measured error. | A real abstract where the two n are cohorts of one model rather than arms of a comparison, showing which reading a surgeon expects. |
| **Negation that never names the group** | Polarity fires on a negator standing near a control phrase, which is what caught *"no hubo grupo control"*. It cannot catch *"los grupos no fueron comparados"* or *"no comparison was made"* — the denial is there and the phrase it denies is not. | A real abstract that denies the comparison without naming it, plus a reading of how often that phrasing occurs. Until then the script under-reads these as silence, which lands on the weaker design (R2) and is the safe direction to be wrong in. |
| **`LOS — mean + IQR`, the corpus's own pairing** | A mean pairs with an SD and an IQR with a median; the corpus pairs a mean with an IQR. The entry is attributed to the operator's reference file, and correcting an attributed entry in silence would make this build the author of a rule it is presenting as his. Both reference files now carry the disputed flag inline instead — the disclosure had been living only inside the changelog. | The operator saying which he meant. Then the entry is corrected with his name on it, or kept with the reason. |
| **Naked magnitudes** | The corpus's rule is real — a magnitude carries its statistic, CI95% or range — but it is in this file, so **it fires no rule ID and the editor does not raise it on its own** — a magnitude with no statistic reaches a critique only as evidence for the R5 claim finding. What is *not* settled: whether a missing CI/p-value is its own finding or evidence for the claim finding — it currently competes for a slot in a three-finding budget. | A decision, not a source. Deferred until real abstracts show which reads better. |

## Rejected

Kept because a rejected idea returning as a fresh good idea is how contracts bloat.

| What | Why not |
|---|---|
| **Copyedit findings, "just as a note"** | R4.5. Every one costs a slot from a budget of three, on the failure class that everyone else in the author's chain already catches. The aside is where scope creep starts. |
| **A confidence percentage on findings** | R3. Evidence instead of a confidence number: `confirmed` / `provisional` / `out-of-scope`, each tied to what can be quoted. A number dressed as a probability is a feeling with a decimal point. |
| **Suggesting the replacement verb** | R9, and the evidence agrees: over half of Haber's reviewers heard cause in *association* anyway (2022). The swap relocates the overclaim and convinces the author it's handled. |
